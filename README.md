# Kolossus Kompanion - Apocalypse Survival Game

A comprehensive companion collectable game set during a meteoric event apocalypse, featuring a massive environment with up to 200,000 collectable companion animals, hunting, fishing, and survival mechanics.

## 🌍 Game Overview

Survive in a post-apocalyptic world where meteor showers threaten humanity's existence. Build a collection of companion animals to help you survive, hunt for food, fish in contaminated waters, and adapt to an ever-changing hostile environment.

## 🎮 Features

### Core Gameplay
- **Survival Mechanics**: Manage food, water, and companion needs
- **Dynamic Environment**: Meteor showers with different types (iron, ice, radioactive, crystal, antimatter)
- **200,000 Possible Companions**: Vast collection system with multiple categories
- **Hunting & Fishing**: Resource gathering with companion assistance
- **Day/Night Cycle**: Time progression affects gameplay difficulty

### Companion System
- **30+ Base Companion Types**: Including mammals, birds, marine life, reptiles, insects, and mythical creatures
- **Rarity System**: Common, Rare, Epic, Legendary, and Mythical companions
- **Skill-Based Abilities**: Companions provide unique skills like hunting, swimming, intelligence
- **Dynamic Name Generation**: Procedurally generated names for each companion
- **Companion AI**: Basic movement and behavior systems

### Environment & Survival
- **Apocalyptic Setting**: Increasing meteor activity and environmental hazards
- **Multiple Terrains**: Forest, desert, ocean, mountains, wasteland, and more
- **Environmental Hazards**: Acid rain, radiation bursts, meteor dust storms
- **Resource Management**: Food and water consumption with companion effects

### Technical Features
- **Web-Based**: Runs in any modern browser
- **Responsive Design**: Adapts to different screen sizes
- **Modular Architecture**: Extensible system for adding new features
- **Visual Effects**: Meteor trails, impact effects, and environmental indicators

## 🚀 How to Play

1. **Open the Game**: Launch `index.html` in a web browser
2. **Manage Resources**: Keep your food and water levels above zero
3. **Hunt & Fish**: Use action buttons to gather resources (costs food/water)
4. **Find Companions**: Click "Search for Companions" or click on the game world
5. **Build Your Collection**: Tame different animals with varying rarities and skills
6. **Survive the Apocalypse**: Adapt to increasing meteor activity and environmental threats

- Meteor activity increases every 5 days
- Environmental hazards become more frequent
